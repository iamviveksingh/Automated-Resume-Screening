# Automated Resume Screening

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Scikit-learn](https://img.shields.io/badge/Scikit--learn-F7931E?style=for-the-badge&logo=scikit-learn&logoColor=white)
![NLP](https://img.shields.io/badge/NLP-Natural_Language_Processing-blue?style=for-the-badge)

An AI-powered resume screening application that automates the candidate evaluation process using **Machine Learning** and **Natural Language Processing**. The system provides objective evaluation, detailed scoring, and intelligent candidate ranking — reducing manual screening effort by **50%**.

## ✨ Key Features

- **NLP-Based Resume Parsing** — Automatically extracts key information (skills, experience, education) from uploaded resumes
- **ML-Driven Candidate Ranking** — Scores and ranks candidates based on relevance to job descriptions using text classification algorithms
- **Keyword Matching** — Identifies critical skill matches between resumes and job requirements
- **Batch Processing** — Handles large datasets of resumes simultaneously
- **Objective Scoring** — Eliminates human bias by providing data-driven candidate evaluations

## 🛠️ Tech Stack

| Layer | Technology |

| Language | Python |
| ML/NLP | Scikit-learn, NLTK / SpaCy |

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/iamviveksingh/Automated-Resume-Screening.git
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application
   ```bash
   python app.py
   ```
